## Entry

> Beautiful planet, baffling locals: they invented instant messages, then invented meetings to discuss the messages. Three stars, would orbit again.

**146 characters** (limit: 200, single line, plain text).

## How it works

`main.py` writes the one-line alien tourist review of planet Earth to
`/output/entry.txt`. It validates the text first — non-empty, a single
line, valid UTF-8, at most 200 characters — and exits non-zero if the
entry cannot pass the gate, so a broken entry is never shipped.

```sh
python3 main.py   # writes /output/entry.txt, prints the character count
```

## Why this line

The laugh comes from the alien's angle on ordinary Earth life: a species
that invented instant communication, then invented meetings to talk about
the messages. It reads like a real tourist review — a verdict ("baffling
locals"), a star rating, and a closing remark ("would orbit again") — with
the punch landing at the end.
